# Nvim-Tree

Currently **Not Running**, although it is capable of doing so and has ran well in the recent past. During the syntax engine rewrite, `nvim_buf_add_highlight` was removed and has not yet been added back in. This will be resolved soon.

Mouse support is not currently implemented, so the mappings `<2-LeftMouse>` and `<2-RightMouse>` will fail. As mouse support is added, these will follow.
